# 单线模拟规则

`World` 以 20 Hz 推进验证地图。场地为 60 × 10 单位，包含双方基地、水晶、外塔和两处遮挡岩石。比赛由水晶实际被摧毁结束。模拟使用连续坐标、稳定实体 ID、固定遍历顺序和显式 seed。相同构建、数据、队伍和逐 tick 输入可以使用 `state_digest()` 对比，摘要包括待命中的弹道、冷却、路径、目标记忆和未公开的实体状态。联邦队列使用 `rules_digest()` 核对模拟源码和外部资料包。

## 战斗和成长

- 从外部 `units.json` 读取英雄、塔和各类小兵的基础数值、每级生命、能量、武器、护甲和护盾。验证地图按 45 秒首波、30 秒间隔发兵，每第四波用队长替换攻城兵。水晶按目标最大血量的 4% 发射攻击并附带减速。
- 普攻遵守射程、视野、出手前摇与恢复时间。远程英雄出手后弹道独立飞行，出手前走位会取消攻击。武器伤害按护甲、法术伤害按护盾计算。验证规则取基础攻击前摇 3 tick、恢复 17 tick、远程普攻弹速 18 单位/秒。完整客户端攻击动画和逐英雄攻速曲线仍需校准。
- 升级经验阈值采用补丁公布的 5v5 公式 `90 + 8 × (当前等级 − 1)`，最高 12 级。附近英雄获得补刀经验和金币，补刀者与附近队友分别结算。小兵 6/12 经验取早期印刷值，35 秒后每秒 0.45 自然经验取资料包的条件性推算。经验平分、10 单位协助距离、基地回复、复活时长和初始技能点属于本项目验证规则。
- 基地内可以买 Weapon Blade、Light Armor、Light Shield、Oakheart、Energy Battery。每件使用其 T1 `cost_a` 和对应命名属性，各扣款、加成、入包一步完成。最多六件。T2/T3 的两个价格字段、合成件和被动原样留在资料包。

## 技能

模拟接口包括 `Learn(A/B/C)` 和 `Cast {slot, target}`。按目标类型检查敌我、范围、视野、能量、等级和冷却。蓄力时走位、攻击、死亡会中断。释放时再次判定目标并扣能量。下表列出本实现覆盖的效果。已命名的 4.13 字段从外部 `official_rules.json` 载入；没有完整数表的前摇、耗能、伤害、距离和持续时间采用代码中的验证规则。`ability_raw.json` 仅保留提取证据。

| 英雄 | 技能 | 实现及数据边界 |
|---|---|---|
| Ringo | A / B / C | A 单体伤害、减速，B 加速并缩短普攻间隔，C 蓄力后追踪弹和三段后续伤害。4.13 确认 Ringo 武器成长，未重印这些技能的完整数值。 |
| Adagio | A / B | A 单体治疗，使用公布的冷却档和 9% 生命系数；B 强化接下来的 5/5/5/5/7 次攻击。本项目实现治疗和强化部分。 |
| Lyra | A | 指定地面区域持续治疗和伤害，使用公布的五档治疗、冷却和生命系数。验证实现按 3 次脉冲结算。 |
| SAW | B | 指定方向持续射击，使用公布的 DPS 和冷却。四个半秒脉冲可被走位打断。 |
| Karas | B | 指定点范围伤害，使用公布的五档伤害。范围、耗能与冷却来自验证规则。 |
| Shin | C | 指定方向连续三次伤害，每次基础伤害 200 源自 4.13。脉冲间隔和宽度来自验证规则。 |

模拟接口与 CE 客户端命令解码分别验证。真实触屏动作在哪个入站消息上携带技能槽和目标，需要逐个用设备确认。

## Bot 与导航

英雄每五步分批决策，考虑技能、撤退、已出手弹道预测的补刀窗口、目标切换成本和塔下友方兵线。避开视线遮挡，最近目击点最多记忆两秒。团队每秒确定己方兵线靠前的位置，英雄跟随推进。英雄在购买、选技和施法时与玩家共享规则。移动优先直接通行；遇到障碍时在固定十节点可视图上执行有界 A*，缓存折线路径。每 tick 至多新建六条路径，每次搜索最多扩展十个节点。

```powershell
cargo test -p halcyon-sim
cargo run --release -p halcyon-sim --example lane_bench -- ../vg/_ana/delivery
```
