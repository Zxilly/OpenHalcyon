# 单线模拟规则

`World` 以 20 Hz 推进对局。单元测试使用 60 × 10 的验证地图。Solo Bots 使用录像标定的中路坐标和十个英雄出生点，ARAL 使用六个席位和该模式的结构坐标。英雄、塔、水晶和兵线均在同一个定步长循环中推进。摧毁敌方水晶即可取胜，ARAL 还支持队伍投降。[Solo 中路](../../docs/solo-lane.md) · [ARAL](../../docs/aral.md)

模拟使用连续坐标、稳定实体 ID、固定遍历顺序和显式 seed。相同构建、数据、队伍和逐 tick 输入可以使用 `state_digest()` 对比，摘要包括待命中的弹道、冷却、路径、目标记忆和未公开的实体状态。联邦队列使用 `rules_digest()` 核对模拟源码和外部资料包。

## 战斗和成长

- 从外部 `units.json` 读取英雄、塔和各类小兵的基础数值、每级生命、能量、武器、护甲和护盾。验证地图按 45 秒首波、30 秒间隔发兵，每第四波用队长替换攻城兵。水晶按目标最大血量的 4% 发射攻击并附带减速。
- 普攻遵守射程、视野、出手前摇与恢复时间。远程英雄出手后弹道独立飞行，出手前走位会取消攻击。武器伤害按护甲、法术伤害按护盾计算。验证规则取基础攻击前摇 3 tick、恢复 17 tick、远程普攻弹速 18 单位/秒。完整客户端攻击动画和逐英雄攻速曲线仍需校准。
- Solo 开局 1 级、600 金币，开战 40 秒后每秒结算 3 金币和 0.6 经验。ARAL 开局 4 级、2,000 金币，开战 30 秒后每秒结算 15 金币和 1.8 经验。房间按模式选择升级曲线，重连时从权威账本恢复余额和累计收入。验证地图保留独立的经验曲线。[原始成长记录](../../docs/native-progression.md)
- 商店可结算 56 种物品，包括录像中 63 种已购模板里的 55 种，覆盖 341 笔配对交易中的 269 笔。直接购买或用已有组件合成都按一次事务更新金币、实例和属性。ARAL 在余额或格位不足时发送拒绝回执。配方、各物品属性和仍需校准的被动效果见[商店明细](../../docs/aral-shop.md)。

## 技能

模拟接口包括 `Learn(A/B/C)` 和 `Cast {slot, target}`。按目标类型检查敌我、范围、视野、能量、等级和冷却。蓄力时走位、攻击、死亡会中断。释放时再次判定目标并扣能量。下表列出本实现覆盖的效果。已命名的 4.13 字段从外部 `official_rules.json` 载入；没有完整数表的前摇、耗能、伤害、距离和持续时间采用代码中的验证规则。`ability_raw.json` 仅保留提取证据。

| 英雄 | 技能 | 实现及数据边界 |
|---|---|---|
| Ringo | A / B / C | A 单体伤害、减速，B 加速并缩短普攻间隔，C 蓄力后追踪弹和三段后续伤害。4.13 确认 Ringo 武器成长，未重印这些技能的完整数值。 |
| Adagio | A / B | A 单体治疗，使用公布的冷却档和 9% 生命系数；B 强化接下来的 5/5/5/5/7 次攻击。本项目实现治疗和强化部分。 |
| Lyra | A | 指定地面区域持续治疗和伤害，使用公布的五档治疗、冷却和生命系数。验证实现按 3 次脉冲结算。 |
| SAW | B | 指定方向持续射击，使用公布的 DPS 和冷却。四个半秒脉冲可被走位打断。 |
| Idris | B | 飞轮去程和回程分别命中，回程追踪施法者，使用独立体力池。[数据与参数](idris.md) |
| Lorelai | A / B / C | 延时眩晕与持续伤害、水池移速、友军护盾与净化。施法会消耗施法者脚下的水池。[数据与参数](lorelai.md) |
| Karas | B | 指定点范围伤害，使用公布的五档伤害。范围、耗能与冷却来自验证规则。 |
| Shin | C | 指定方向连续三次伤害，每次基础伤害 200 源自 4.13。脉冲间隔和宽度来自验证规则。 |

九份实机通道档案里有 24 条学习请求、15 条点地施法和一条指定友方的施法。原版协议入口已接通四种英雄模板的已知学习槽，以及 Idris B 和 Lorelai A/B/C 的释放。其余表中技能可由模拟接口驱动，逐英雄原版输入映射仍需样本验证。[学习、施法与释放记录](../../docs/native-abilities.md)

## Bot 与导航

默认难度下英雄每五步分批决策。服务端将原版菜单的五档难度映射为每 16、10、5、3、2 个 tick 决策一次。Bot 考虑技能、撤退、已出手弹道预测的补刀窗口、目标切换成本和塔下友方兵线。避开视线遮挡，最近目击点最多记忆两秒。团队每秒确定己方兵线靠前的位置，英雄跟随推进。英雄在购买、选技和施法时与玩家共享规则。移动优先直接通行；遇到障碍时在固定十节点可视图上执行有界 A*，缓存折线路径。每 tick 至多新建六条路径，每次搜索最多扩展十个节点。

```powershell
cargo test -p halcyon-sim
cargo run --release -p halcyon-sim --example lane_bench -- ../vg/_ana/delivery
```
