# 2026-11-20 本机 CE 负载测试

Ryzen 9 9950X3D，16 核 32 线程，Windows 11 build 26200。每个被测服务端进程固定在一颗逻辑 CPU，单个 Tokio 线程，Windows Job Object 提交内存上限 1 GiB。负载进程使用不同的逻辑 CPU，运行在同一宿主机。各配置读取外部 4.13.4 数据包。连接走回环 HTTPS 和双 GS TCP。初次登录和选人后的稳定期用于计算下表，后续自然结算、重新登录游戏连接、重新入局都计入时间。场景间共享宿主机内存、缓存和操作系统调度。

CPU 均值和最高约 60 秒滚动均值按被测服务端 PID 的 CPU 时间计算。RSS 为每五秒采样的工作集峰值。tick 从原计划时刻算到模拟广播入队完成，超时列使用整个区间内的累积计数。滚动 p99 是各房间最近最多 1024 步 p99 的采样最大值。每玩家下行含 GS 长度头，分母为配置的真人席位数，不计平台请求、TCP/IP 头或重传。

### 分批登录

同一服务端镜像、64 个房间、640 名玩家，初次登录均匀错开 90 秒。负载端 SHA-256 为 `1477c665c9ebeba57e9511de8f2b24917206e1092f7e0acf845867931d963d99`。

| 服务端逻辑核 | 负载进程逻辑核 | 观测 |
|---|---|---|
| 16 | 17、19、21、23 | 92 秒建满 64 局。随后普通连接意外断开，测试提前失败，最后一次采样的房间最大 tick 超过 2.68 秒。 |
| 4 | 20、22、24 | 建满 64 局，再测 150.8 秒。0 / 192954 步超过 40 ms，最高滚动 p99 为 17.87 ms，滚动 CPU 最高 48.15%，RSS 36.99 MiB，平均每人下行 5173 B/s。 |

Windows 处理器拓扑显示 16 和 17 是同一物理核的两个 SMT 线程，4 与 20、22、24 属于不同物理核。两次测试期间宿主机上仍有其他作业，结果无法单独归因于分批登录策略。
